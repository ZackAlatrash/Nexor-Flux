# UI Map

## Today
Daily logging screen and app start destination. Supports macro totals, body metrics, recovery scores, training toggle, notes, meal entry, saved meal quick-add, delete meal, and copy yesterday.

## Dashboard
Shows targets, today totals, 7-day weight average, trends, adherence, logged-day count, and deterministic calorie verdict with reason codes.

## Progress
Vico line charts for weight, waist, calories, protein, carbs, fat, adherence, and marker lift estimated 1RM. Supports 7, 14, and 28-day filters and empty states.

## Plan
Edits calorie target, macro targets, phase start date, weight threshold, waist threshold, adherence minimum, review cadence, and units.

## More
Routes to Foods/Meals and Settings.

## Foods/Meals
Adds/deletes saved foods and saved meals. Saved foods and meals can be quick-added to today's log.

## Settings
Exports/imports local JSON backups, resets logs, resets all local data, and displays Gemma MVP status.
