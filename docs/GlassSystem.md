# Glass Design System

How the four glass tiers work and when to use each one.

---

## The Four Tiers

### Neutral Glass — `NeutralCard {}`

The workhorse. Barely visible — just enough to separate a card from the background without drawing attention.

**Visual:** 4% white fill, hairline 7% white border, no blur. Looks like a very faint dark surface.

**Use when:**
- The card is a list row or repeating item (food log slots, library entries)
- The card is a container for a form or settings rows
- There are many of these cards on screen at once
- The card is secondary information — menus, actions, edit-mode controls

**Do not use when:** the card contains the primary insight or metric for the screen.

**Examples in the app:** Breakfast / Lunch / Dinner slot cards, menu rows in More, range selector (7d/14d/28d), mini chart pairs.

---

### M3 Frosted Blur — `FrostedCard {}`

The primary data surface. Clearly glass — you can tell the background is behind it. Based on Material 3 Expressive's `GlassContainer`.

**Visual:** 62% dark fill with `blur(24px)` backdrop, 13% white border with a subtle shimmer line at the top edge.

**Use when:**
- The card shows the primary metric or summary for the screen (today's calories, nutrition strip)
- The card contains a chart that tells the data story for a full section
- The card is a form that the user is actively filling in (body check-in)
- There are 1–2 of these per screen, not many

**Do not use when:** there are many identical repeating rows — use Neutral instead.

**Examples in the app:** Today card on Dashboard, Nutrition strip on Food Log, all chart cards on Progress (Weight, Calories, Waist), body check-in form card.

---

### Tinted Glass — `TintedCard {}` *(reserved — not in use yet)*

Reserved for AI-powered features. Carries the app's violet brand colour as a glass tint, signalling that this content is generated or intelligent rather than raw data.

**Visual:** 9% violet fill with `blur(16px)` backdrop, violet border with violet shimmer line at top, ambient violet glow.

**Use when:**
- AI Insights card (on-device analysis result)
- Weekly adjustment verdict (AI-generated recommendation)
- Plan suggestion banner
- Any content generated by the AI layer, not entered by the user

**Do not use** for any card that displays data the user logged themselves. The violet tint means "the app is telling you something," not "here is your data."

**Status:** The composable exists and is ready. No call sites until AI features ship.

---

### Liquid Glass — FletchMcKee/liquid library

Chrome only — never a content card. The most visually prominent tier, with a bright specular arc at the top and deep shadows. Uses Apple iOS 26 geometry: full pill shape (`borderRadius = 100dp`).

**Visual:** White-tinted glass with a pronounced highlight arc, strong shadow, full pill shape. Implemented via the FletchMcKee/liquid Compose library — do not hand-roll this effect.

**Use when:**
- The element is navigation chrome (bottom nav pill)
- The element floats over content (bottom sheet overlay, modal dialog)
- The element is a primary interactive button that floats (the `+ Add` button inside meal slots, a FAB)
- The element is a system overlay (confirm/delete dialog)

**Do not use for content cards.** Liquid Glass catches the eye by design — it is meant to signal "tap here" or "this is navigation," not "here is your data."

**Examples in the app:** Bottom nav pill, `+ Add` slot buttons, bottom sheet overlays, confirm dialogs.

## Quick Reference

| I'm building… | Use |
|---|---|
| A list of repeating rows | Neutral |
| A form the user fills in | M3 Frosted |
| The main calorie / macro summary | M3 Frosted |
| A chart (weight, calories, etc.) | M3 Frosted |
| Settings or menu rows | Neutral |
| A navigation pill | Liquid Glass |
| A modal / bottom sheet | Liquid Glass |
| A floating action button | Liquid Glass |
| An AI-generated insight *(future)* | Tinted |
| A plan recommendation *(future)* | Tinted |

## Corner Radius Tokens

| Token | Value | Used on |
|---|---|---|
| `CornerSmall` | 10dp | Inputs, step buttons, small controls |
| `CornerCard` | 16dp | All content cards (Neutral, Frosted, Tinted) |
| `CornerChip` | 20dp | Badges, pill indicators, tag chips |
| `CornerPill` | 100dp | Liquid Glass elements only |

All content cards use `CornerCard = 16dp`. Never mix radii on card containers.
